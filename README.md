# PavosTouch
Control Ganadero de pavos

## Arepas · Mini empresa (`/arepas`)
App para un vendedor de arepas con el mismo formato del Control de Ruta (hoja tipo Excel):
ventas, cartera (cuentas por cobrar y por pagar), clientes, inventario con producción, compras,
gastos, informes / cierre de caja en PDF y copia de seguridad. Los datos se guardan en el celular.
